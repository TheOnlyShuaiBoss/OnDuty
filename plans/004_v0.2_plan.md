- 用户补充场景: ZCode 免费额度窗口为夜间 23:00–09:00 → "定时任务替人守夜"是首个真实生产用例,验证目标应瞄准它

## 范围(对主方案 §11 v0.2 的落细)

1. **once_at**: 一次性定时(`2026-09-17 23:05`)。config 解开 v0.1 拦截;状态记 `fired_at`,执行后归档不重复
2. **失败重试**: job 级 `retry: {max: 2, backoff_minutes: 5}`;默认不重试。重试在 daemon 内排期(不阻塞其他 job;v0.1 全局串行下即"延后重排")
3. **按 workdir 并行**: 调度器从"全局串行"升级为"每 workdir 一把锁",不同目录可并发;同目录严格串行。线程模型: 每锁一个 worker 线程,主循环只派发
4. **auto_git_worktree**: `safety.auto_git_worktree: true` 时,job.workdir 是 git 仓库 → 自动 `git worktree add` 到 `state/worktrees/<job>-<ts>`,跑完输出分支名;失败不清理(留现场);成功可选保留(默认保留,由用户 git worktree remove)
5. **状态目录可配置**: `state_dir` 默认 `<config目录>/state`,允许全局覆盖(便于多实例)
